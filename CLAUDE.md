# Continuous Claude v3 Project Instructions

## Autonomous Work Pattern

**CRITICAL: Always continue working after providing a summary.**

When the user asks you to "continue" or work autonomously, you should:
1. Work through multiple tasks without stopping
2. Provide periodic summaries of progress
3. **Continue working after each summary** - do not wait for user confirmation
4. Only stop when explicitly asked or when all tasks are complete

If you provide a summary of completed work, immediately continue with the next task in the sequence unless the user says otherwise.
